## A1　`aplift` 的计算式（追认）

计划 §1/§2 登记了「`AP-lift` 用 `ε = 0`」，但没写计算式。实现采用：

```
aplift = pr_auc − test_pos_rate
```

其中 `pr_auc` 是该跑的 `pr_auc` 列，`test_pos_rate` 是该跑自己的测试集正类比例。

**验证**：用该式重算的 `all`/`eps=0` 胜率与正文表 4 的 AP-lift 列**逐格完全一致**：

| 数据集 | LSTM | TCN | Transformer | RF | HGB |
| --- | --- | --- | --- | --- | --- |
| CIC17 表 4 | 9.4 | 41.1 | 27.8 | 18.3 | 3.3 |
| CIC17 重算 | 9.4 | 41.1 | 27.8 | 18.3 | 3.3 |
| CIC18 表 4 | 7.2 | 8.9 | 18.9 | 31.1 | 33.9 |
| CIC18 重算 | 7.2 | 8.9 | 18.9 | 31.1 | 33.9 |

10 个数字差 0.0，所以该定义不需要再有第二种解释。

## A2　组内「平分胜」的实现细节（追认）

计划 §2.0：「与最大值之差 `≤ ε` 的模型平分这一胜」。

实现：

```
M     = 该组（cell, seed[, fold]）内 5 个模型的指标矩阵
mx    = 组内最大值
win   = (M >= mx - ε - 1e-12)      # 1e-12 为浮点容差
share = win / win.sum(axis=1)      # 并列 k 个各得 1/k
```

`1e-12` 的容差是必需的：`roc_auc` 以 double 存储，`ε=0` 时若不加容差，
数学上相等的两个值可能因最后一位不同而被判成不并列。加容差后 `all`/`eps=0` 复现表 4 最大差 0.00pp。

## A3　`best_model_auc` 的口径（追认）

WP5 的「同格最好模型 AUC」= `det_*.db` 中该格**各模型跨种子平均 AUC 的最大值**，
不是「该格最高单跑」。前者更稳（不受单跑运气影响），且与表 4/表 5 的跨种子聚合口径一致。

## A4　`floor(p)` 与塌陷判据（追认，无变化）

```
floor(p) = max((1-p)/(2-p), p/(1+p))      # 取值范围 [1/3, 1/2]
excess   = macro_f1@0.5 − floor(p)
塌陷     ≡ excess < δ = 0.02
```

`p` 逐跑按该跑自己的测试集正类比例计算，不用全局常数。

## A7　WP2e 字段定义（追加登记，落库之前写入）

规范 §2 WP2e 列了 8 个字段名但没给口径，这里逐条定死。**本节只补定义，不改任何判定阈值。**

| 字段 | 定义 |
| --- | --- |
| `pos_q10/q50/q90` | 测试集中 `label == 1` 的序列分数的 10/50/90 分位（`numpy.quantile` 默认线性插值） |
| `neg_q10/q50/q90` | 同上，`label == 0` |
| `val_pos_q50` / `val_neg_q50` | **验证折**（`make_split` 返回的 `val`）上的同类量。RF / HGB 只用训练折拟合，验证分数来自拟合后对 `va` 的 `predict_proba`；序列模型的验证分数取早停结束后恢复的最优权重 |
| `frac_pos_above_05` | `mean(score[label==1] >= 0.5)` —— 回答「本该报警的正类序列里，真正报出来的占多少」 |
| `pred_true_ratio` | `#{score >= 0.5} / #正类`（沿用 §0.3 定义，不做改动） |
| `thr_oracle` | 在**测试集**上使 macro-F1 最大的阈值，判定式仍为 `pred = 1[score >= thr]`；候选阈值只取并列分数组的**边界**，另加「全判负」候选（记 `thr = +inf`）。这是**描述性上界**，不是可部署规则，用途仅为回答「分数里还剩多少排序信息」 |
| `macro_f1_oracle` | 与 `thr_oracle` 对应的 macro-F1 |

**族标签 `family`**（落实 §4 已登记的规则）：以模型**实际看到的 T 步窗口**（`truncate` 之后）内的攻击流行取众数、并列取字典序最小；序列不含攻击流则记 `BENIGN`。
另存 `family_full`（以该段**全部行**取众数），使「整段口径」与「窗口口径」两种读法都可复核；正文只用 `family`。

**UNSW 的族标签**：该数据集 `Label` 列是 0/1，族改取 `_Attack` 列（下划线开头，不进特征）。
CIC17 / CIC18 一律用 `Label` 原始字符串，**不做归一化合并**（§4 原条款）。

**分数文件命名**：`scores_v2/{dataset}/{安全化 run_id}.npz`。`run_id` 含 `|` 与 `/`，直接当文件名会造出目录，故把 `[^A-Za-z0-9._-]` 统一替换为 `_`；原始 `run_id` 存在 npz 内并写进 DB 的 `score_file` 列，可无损还原。

**一致性闸门**（规范要求「先核对 `macro_f1` 与旧库逐位一致」）：

逐条比对 7 个字段 —— `macro_f1 / f1_pos / fpr / pr_auc / mcc / roc_auc / epochs`，
**任一不等即终止，不进入后续 WP2a–WP2d**。
之所以把 `epochs` 一并纳入：它由验证集 macro-F1 轨迹决定，比单看 `macro_f1` 更灵敏，
早停轨迹一旦漂移会先在这里暴露，而单看 `macro_f1` 可能因为并列取整而漏掉。

**验证集预测的实现方式**：`scripts/run_pilot.py` 的 `train_seq` 内部算过验证集概率但未返回，
而 `scripts/` 是只读目录，故在 `scripts_v2/seqmodels_v2.py` 里做**逐行拷贝 + 多返回一个向量**。
数值等价性不靠阅读保证，由上面那道闸门逐位证明。

## A9　WP2c（S1 / S2 / S3）的操作化定义（追加登记，**在任何 2c 结果落库之前**）

规范 §WP2c 只给了三行描述，下面把它写成可执行的口径。**不改任何判定阈值**
（决策表第 3、4 行的阈值原样沿用 §1.1）。

### 数据集与规模

只在 **CIC18** 做，取日 `d0–d4`（与 S0 相同，`--cic18-days 0 1 2 3 4`）。
S1、S2 各 **9 格 × 5 模型 × 10 种子 = 450 跑**，共 900 跑，写入
`results_v2/splits_cic18.db`；S3 不训练，在 S0（`det_v2_cic18.db`）的分数上离线做。

### S1 `block_strat`：时间块分层随机 60/20/20

- **时间块** = `wid // 600`，`wid` 是该序列段内**最早一条流的全局秒数**
  （跨日累加，因此块不会跨日）。同一条流只属于一个块 → 会话不跨集，满足
  「按 10 分钟块切，避免同一会话跨集」。
- **分层键** = 该块是否含至少一条正类序列（`block_pos`）。含攻击的块与纯良性块
  **各自**按序列条数贪心切 60/20/20，使两层的正类率与整体一致。
- 层内块数 < 3 时整层进训练（会在日志打印）；否则保证验证、测试各至少 1 块。
- 随机种子 `0`（与 `make_split(seed=0)` 同约定）。切分在**抽样之后**的序列集合上做。

### S2 `cross_day_ext`：训 d0–d3、验 = 训练日时间序尾部 20%、测 d4

- 训练 + 验证 = 日 0–3 的全部序列，按 `wid` 升序排；**尾部 20%**（整除取整，至少 1 条）为验证，
  其余为训练。
- 测试 = 日 4 全部。与 S0 相比只多给了模型 d3（2018-02-20，含 `DDOS-LOIC-HTTP` / `DDOS-LOIC-UDP`）。

### S3：离线先验对齐（不训练）

- 取 S0 每个跑的测试日分数（`scores_v2/cic18/`）。**良性序列全保留**，对攻击序列
  **无放回下采样**，使下采样后测试正类率 = 该格的**训练先验** `p_tr`。
- `p_tr` = 同一批序列在 **S0 的 `cross_day` 训练折（d0–d2）**上的序列级正类率，
  由 `splits_v2.s0_train_pos_rate()` 在造库时一并算出，写入
  `results_v2/wp2c_prior.csv` 的 `pos_rate_train_s0` 列（不在事后重估）。
- 下采样重复 **20 次**（种子 `20261101 + k`，`k = 0..19`），每次重算 `macro-F1@0.5`
  与 `excess`，报 20 次的**均值**与塌陷率；同时报这 20 次的 2.5/97.5 分位。
- 若某跑测试正类数已 ≤ 目标数，则该跑不做下采样，原样计入。

### 报什么

规范要求：每种划分报**塌陷率及 95% CI**、`pred_true_ratio` 中位、`AUC` 中位、**按模型塌陷率**。
三者（S1/S2/S3）与 S0 并列，输出 `results_v2/wp2c_splits.csv`。
塌陷率与分模型塌陷率的 CI 用 **Wilson 95%**（比例量，与 WP2a 一致）；
汇总稿写 `results_v2/WP2C_SUMMARY.md`。

### A10.5 先验对齐臂的实现规则（先写死，避免事后挑选）

1. 先算同格上 `inf_U` 的训练正类率 $p_U$ 与 `inf_S` 的 $p_S$（均在**同一抽样池**内）。
2. 若 $p_S > p_U$：对 `inf_S` 中 **d7 的攻击序列**做无放回下采样，保留 $k$ 条使
   $(pos_{012} + k)/(n_{012} + k) = p_U$；良性序列一条不丢；采样种子 = 训练种子。
3. 若 $p_S \le p_U$（**盘点预测会落在这一支**：d3 的 LOIC-HTTP 远多于 d7 的 NMAP）：
   按规范的回退规则，改为对 `inf_U` 中 **d3 的攻击序列**下采样，使先验等于 $p_S$。
   此时该臂在语义上是 **`inf_U` 的先验对齐版（U-pm）**，臂名仍记 `inf_P`，
   落库列 `prior_match_side` 记 `U` 或 `S`，并在报告中写明。
4. 若 $k$ 超过该日攻击序列总数（无法达标的低先验），取全部并在 `prior_match_note` 记 `capped`。

预估值（盘点数据，仅作合理性检查，不作为结论）：tw30s 上 $p_S \approx 234/5{,}719 = 4.09\%$
低于 $p_U \approx 308/5{,}648 = 5.45\%$，host 上 $8.66\%$ 低于 $9.76\%$ —— 因此**走第 3 支**。

### A10.6 判定标准（照抄规范 §3，跑完不得改）

**主量**：每组每臂的塌陷率（`excess < 0.02`）及 Wilson 95% CI；配对差（同 cell、model、seed）
$S-U$ 与 $P-U$ 的簇 bootstrap 95% CI（组 = cell × seed，10,000 次，种子 20261101）。

**辅助量**：`pos_q50`、族内 AUC、`recall_at_05`、`pred_true_ratio`、`tpr_at_fpr_1pct`；
按路线拆分，并单独报 `tw30s`。

| # | 如果结果是 | 论文这样写 |
|---|---|---|
| 1 | 至少一组符合：S 与 P 的塌陷率均比 U 低 ≥ 20pp，配对差 CI 不含 0，且 S/P 的 `pos_q50` 在 0.5 以上、U 的在 0.5 以下 | §6.2.5 候选三加一段"数据集内干预"；§8 第 8 条改写为"已在同一数据集内干预验证"；结果表进正文 |
| 2 | S 比 U 低 ≥ 20pp，但 P 与 U 相差 < 10pp | 写"已见族的改善主要来自训练先验变化"，§6.2.5 候选二判定收窄 |
| 3 | 两组都是 S 与 U 相差 < 10pp | 机理维持现稿，§8 第 8 条加一句"数据集内对照未能支持"并报数字；结果进补充材料 |
| 4 | 某组 U 与 S 的 AUC 中位都 < 0.80 | 该组不支持也不反对机理，只报描述（Infilteration 常见） |
| 5 | 某组被门槛取消 | 只用另一组；两组都取消就维持现稿，并在报告中说明原因 |

**本轮的适用情况**：Web 走第 5 行（取消），Inf 逐条判。
