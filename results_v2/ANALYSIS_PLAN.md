## 0. 全局口径（所有 WP 共同遵守）

### 0.1 六条硬约束（违反任何一条，本轮结果作废）

1. **确定性内核**：`cudnn.benchmark=False`，所有新跑记录 `cudnn_benchmark` 字段。
2. **不调超参**：模型、优化器、早停、`T=20`、`δ=0.02` 全部沿用 §5.2 / §3.3 的设置。
3. **种子**：CIC17、CIC18 每格 20 个（0–19），UNSW 补到 20 个（见 WP3）。不许事后挑种子、删跑或剔除"异常跑"。
4. **先写分析计划再跑**：每个 WP 开工前，把"要算哪个量、用什么检验、判定阈值"写进本文件并提交 git，跑完后不得修改判定阈值。
5. **每个进入正文的数字**，都必须能由一条命令从 `results_v2/` 重算出来；命令写进 `results_v2/NUMBERS.md`。
6. **所有统计报效应量 + 95% 置信区间**，不只报 p 值。

### 0.2 禁止事项

- 不新增数据集、不新增模型、不做新检测器。
- 不改写已核实的旧数字；旧数字若与新跑冲突，两个都报并说明。
- 不在正文里保留任何"初稿算错过 / 给自己看 / 我们拒绝回答"类自述。
- 不编造参考文献；检索不到 DOI 的条目一律标 `UNVERIFIED`，核实前不采用。

### 0.3 核心量定义（沿用旧稿，不重新论证）

- 平凡地板：`floor(p) = max((1-p)/(2-p), p/(1+p))`
- 超额：`excess = macro-F1@0.5 − floor(p)`；**塌陷 ≡ excess < δ = 0.02**
- `p` = 测试集正类比例（逐跑按该跑自己的测试集计算）
- `pred_true_ratio` = 预测为正的序列数 / 真实正类序列数（"判太少 0.0007×"即此量）
- 逐跑公共列（所有逐跑文件必须含，缺一列视为不合格）：
  `run_id, dataset, split, fold, cell, route, padding, model, seed, class_weight, cudnn_benchmark, commit, ts`

## 2. WP1 离线稳健性分析（不训练，只读 `det_*.db`）

**目的**：给每个排名类结论加上路线子集、打平容差和置信区间，确定哪些能留在头条。

### 2.0 统一定义（原样拷贝）

- **组** `g = (cell, seed)`（UNSW 再加 `fold`）。组内对五个模型按指标取最大值；与最大值之差 `≤ ε` 的模型**平分**这一胜（每个并列模型各记 `1/k`，`k` 为并列个数；`Σ_model winrate = 1`）。
- **ε 取值**：`excess` 与 `AP-lift` 用 `ε = 0`；`ROC-AUC` 用 `ε ∈ {0, 0.001, 0.005}`。
- **路线子集**：`all`、`tw30s`、`host+service`。
- **Bootstrap**：以**组**为单位有放回重抽 **10,000** 次，取 **2.5% / 97.5%** 分位，随机种子固定为 **20261101**。
- 五个模型：`rf`、`hgb`（或对应树模型）、`lstm`、`tcn`、`transformer`（以 `det_*.db` 实际 `model` 字段为准，不重命名）。

### 2.1 `1a` 胜率矩阵

- **设计**：数据集 `{CIC17, CIC18, UNSW-f0, UNSW-f1}` × 路线子集 × 指标 `{excess, roc_auc, aplift}` × ε。
- **输出**：`results_v2/wp1_winrate.csv`
- **列**：`dataset, fold, route_subset, metric, eps, model, winrate, ci_lo, ci_hi, n_groups`

### 2.2 `1b` Kendall τ

- **设计**：对每个数据集 × 路线子集，算 `τ(excess, roc_auc)` 与 `τ(excess, aplift)`，分别用**胜率聚合**和**均值聚合**两种口径。
- 给出 `n = 5` 的**精确置换 p**（枚举全部 **120** 种排列），以及 **bootstrap 下 τ < 0 的比例**。
- **输出**：`results_v2/wp1_tau.csv`

### 2.3 `1c` 配对效应量

- **设计**：对每个数据集的**每对模型**，算逐组 `ΔAUC` 的：
  - 中位数
  - **Hodges–Lehmann** 估计及 95% CI
  - `|Δ| < 0.001` 的占比
  - 等效性检验 **TOST**，等效边界 **±0.005**，单侧 **α = 0.05**
- **输出**：`results_v2/wp1_pairs.csv`

### 2.4 `1d` 效应摆幅的 CI

- **设计**：分段、填充、模型三种摆幅（**边际均值 `max − min`**）在 `excess` 与 `ROC-AUC` 下的值，以及两者的**比值**（"÷22"等）。
- 用**格内重抽种子**的 bootstrap 给 CI（种子 `20261101`）。
- 另在 `tw30s` 子集上**单独**算填充与模型摆幅。
- **输出**：`results_v2/wp1_swings.csv`

### 2.5 `1e` 方差分解

- **设计**：正文 §5.4 声称做了二因子 `η²`，但全文没报数字。要么算出来（**分段 × 填充 × 模型**，两种指标各一张），要么在 WP7 删掉这句。
- **输出**：`results_v2/wp1_eta2.csv`

## 3. WP5 J1 零特征基线补全（离线，约 1 小时）

- **目的**：现在只有一个 `F1 = 0.9834`，没写是哪个数据集、哪条路线。
- **做法**：对三个数据集（UNSW 分两折）、`host` 与 `service` 两条路线，计算零特征键基线：
  - 分数 = 该键在**训练期**的攻击率；
  - 训练中**没出现**的键用**全局训练攻击率**。
  - 判定阈值固定 `0.5`。
- **报**：`macro-F1@0.5`、`ROC-AUC`、测试键在训练中出现过的比例、同格最好模型的 AUC。
- **输出**：`results_v2/wp5_j1.csv`
- **验收**：能复现 `0.9834`，并写明它属于哪个数据集与哪一格。

## 4. WP2b 攻击族标签规则（规范要求写进本文件）

> 规范 §2 WP2b：「序列攻击族标签规则：取序列内攻击流的众数原始 `Label`；并列取字典序第一个。把规则写进 ANALYSIS_PLAN。」

- 序列的攻击族标签 `family` = 该序列包含的**攻击流**（`Label ∉ {BENIGN, Benign, benign}`）的**原始 `Label` 字符串众数**；
- 若众数**并列**，取**字典序最小**的那一个；
- 若序列**不含任何攻击流**，`family = "BENIGN"`；
- 良性与攻击的原始标签判定以各数据集 `Label` 列原始取值为准，不做归一化合并（`DDoS` 与 `DDoS attacks-LOIC-HTTP` 视为不同族）；
- `seen_in_train` = 该 `family` 是否在训练日中作为攻击流标签出现过（布尔）。

**输出**：`results_v2/wp2b_family.csv`
